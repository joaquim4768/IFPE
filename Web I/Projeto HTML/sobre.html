Descrição do Sistema:

O sistema consiste em um site de venda de veículos, desenvolvido com páginas de login, recuperação de senha e cadastro de usuário. O sistema também possui formulários, tabelas, links de navegação entre as páginas, um cabeçalho de navegação e uma página de produtos com carrinho e simulação de finalização da compra. Além disso, foi utilizado um pequeno recurso em JavaScript para exibir um alerta após a finalização da compra.

Dificuldades Encontradas:

A maior dificuldade durante o desenvolvimento foi, sem dúvida, a organização e estilização das páginas. Como não foi permitido utilizar CSS, centralizar e alinhar os elementos se tornou bastante trabalhoso, sendo necessário utilizar diversas vezes o &nbsp; para ajustar o espaçamento entre os elementos. Além disso, as imagens possuíam tamanhos diferentes e precisaram ser redimensionadas utilizando o atributo width diretamente nas tags HTML. Dessa forma, foi possível manter o projeto desenvolvido em HTML, com a exceção do uso pontual de JavaScript para exibir um alerta ao finalizar a compra.
